# 觅码 · 前端五项界面改进 设计文档

日期：2026-08-27 · 状态：已确认 · 上游依据：`2026-08-25-觅码-UI设计规范-design.md`（视觉体系）、`2026-08-24-觅码-收录与浏览-design.md`（功能与数据）

## 1. 背景与范围

针对觅码前端的 5 条改进需求（原文见 `前端改进/前端改进.txt`）：

1. 个人主页头像后的背景只盖住头像一半——横幅需延伸至「我的仓库」一行上方
2. 多个页面页脚出现在页面中部——页脚须始终守在视口底部
3. 参考 skillsmp 仓库页重新设计觅码仓库页（左滚动右固定的双列形态）
4. 主色调杏色加重，拉开背景与功能区差别且不突兀
5. 「收藏」「点赞」文字按钮改为图标：心形（粉）/ 五角星（金）

本文档只管上述改动的外观与交互；功能逻辑以两份上游 spec 为准。仓库页采用**方案一·布局级重构**：保留现有状态机、URL 深链与乐观更新逻辑，仅重排 JSX 外壳并新增小组件。

过程产出：本方案经由可视化伴随工具逐屏比对确认（横幅三选一选 B、杏色四档选中档、图标配色与形态修正稿均已上屏确认）。

## 2. 决策记录

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 横幅样式 | B：深蓝底白字（B 站空间页气质），背景覆盖至 tab 栏上方 |
| 2 | 杏色档位 | 中档：页面底 `--bg3` → `#F4E4C2` |
| 3 | 图标点亮色 | 心 `#D84870`、星 `#E9A63C` |
| 4 | 未点亮态 | 与点亮同一图形，中空不填色、深色粗描边轮廓（此前「白线条描芯片」的理解作废） |
| 5 | 星星尺寸 | 整体等比放大（29px vs 心 26px），上下顶点与心形对齐 |
| 6 | 计数显示 | 两按钮均为「图标+计数」；心用现成 likes，星用新增可选字段 `favorites_count`，后端就绪前星星旁不显数字 |
| 7 | 推荐补位 | 严格只用同分类仓库，不足不跨类补齐 |
| 8 | 创作者入口 | 「浏览创作者其他仓库」→ 站内个人主页 `/user/:login` |
| 9 | README 渲染 | react-markdown + remark-gfm，不启用原始 HTML 注入 |
| 10 | 实现深度 | 方案一：布局级重构（非全页重建、非保守叠加） |

## 3. 逐条设计

### 3.1 个人主页横幅延伸

**结构**：`.profile-head`（头像+昵称+签名+数据行）整体移入 `.profile-banner` 容器内；横幅从顶栏正下方铺到 tab 栏上沿，原 `-48px` 骑线偏移删除，`.profile-page` 内不再有独立头部区。

**视觉**：

```css
.profile-banner {
  background:
    radial-gradient(circle at 1px 1px, var(--dot_texture) 1px, transparent 1.5px),
    var(--profile_banner);
  background-size: 22px 22px, 100% 100%;
}
```

新增 token（裸色值仍集中于 theme.css）：

| Token | 值 |
|---|---|
| `--profile_banner` | `linear-gradient(135deg, #0A4E8A 0%, #15619E 60%, #2E77AE 100%)` |
| `--on_banner` | `#FFFDF8`（横幅上的主文字/主数字） |
| `--on_banner_dim` | `rgba(255,254,251,.72)`（签名、统计标签等次级白） |

昵称/签名/统计改用 `--on_banner` 系；数字仍 500 字重；头像保持品牌蓝底 + 白圈描边 + 阴影。签名就地编辑输入框在蓝底上加 `--bg1` 底保证可读可用。

### 3.2 页脚守底修复

根因：无任何结构性约束，各页内容短于视口时页脚停在屏幕中部。

修复：`App.tsx` 最外层加壳，五个路由页面为同一个 flex 列的子元素：

```css
#app-root { display: flex; flex-direction: column; min-height: 100dvh; }
#app-root main { flex: 1; }
```

页脚作为最后一个子元素永远沉底。TopBar 的 sticky、LoginModal 的 fixed、`.profile-banner` 全宽均不受影响。验收：任意短内容页（含空态/加载态/错误态分支）页脚都贴住视口底。

### 3.3 色彩 Token 校准

| Token | 现值 | 新值 | 说明 |
|---|---|---|---|
| `--bg3` | `#FAF2E0` | `#F4E4C2` | 页面底加深，功能区差别突出 |
| `--bg2` | `#FCF7EA` | `#F9EFDB` | 保持 卡片 > 次级填充 > 页面底 的明度顺序 |

其余 token（文字/线条/品牌蓝/琥珀/功能色）不动。联动校验清单：页脚与页面底仍有差、吸顶 tab 栏清晰、正文对比度余量充足（`--text1` 对新底 ≈11:1）、封面 SVG 与胶囊混色基于 `--bg1` 不受影响、既有空态插画 PNG 截图目检一轮。

### 3.4 IconAction 组件（替换文字版「收藏/点赞」）

新增 `components/IconAction.tsx`：

```ts
interface Props {
  kind: 'like' | 'favorite'
  on: boolean
  count?: number        // undefined/null 时不渲染数字
  busy?: boolean
  onClick(): void
}
```

**视觉**：

- 未点亮：中空图形，`fill: none`，描边 `var(--text1)`、宽 2.2px、圆角连接
- 点亮：心实心 `var(--like_pink)`（`#D84870`），星实心 `var(--fav_yellow)`（`#E9A63C`）
- 尺寸：心 26×26，星 29×29（同一 viewBox 路径整体绘制放大），二者上下顶缘对齐
- 点亮瞬间播一次弹动 `scale 1→1.2→1`（.3s）——全站唯一保留的形变动画
- 计数：图标右侧 13px/500/tabular-nums，`--text1`
- busy 时图标透明度 .55 且禁止再点击

**行为**：未登录点击走现有登录弹层 gate；失败回滚沿用现有乐观更新逻辑；`aria-label`「点赞/收藏」+ `aria-pressed`；键盘可聚焦触发。

**数据**：`RepoCardData` 新增可选 `favorites_count?: number`；mock 数据直接供数；真实后端就绪前星星旁无数字，不做前端造假。

### 3.5 仓库页双列布局

```
┌─ page-shell ────────────────────────────────────────────────┐
│ ┌─ repo-main 左列（随页滚动）──────────────┐ ┌─ rail 右列 ───┐ │
│ │ 名称 20px + tagline + topics            │ │ 作者卡         │ │
│ │ 元信息: ★stars·●语言·浏览·发布·来源      │ │ 头像+名称      │ │
│ │            ♥23 ☆67 ← 右端              │ │ [跳转GitHub↗] │ │
│ ├─ Tabs: 文件预览 | 仓库解读 ──────────────┤ │ [创作者其他仓库]│ │
│ │ 文件树240px + CodeView / 解读占位        │ ├─ 同类推荐×3 ───┤ │
│ ├─ 自述文件：README Markdown 渲染          │ │ [RepoCard]×N  │ │
│ ├─ 讨论（现状文案不变）                    │ └───────────────┘ │
│ └────────────────────────────────────────┘                   │
└─────────────────────────────────────────────────────────────┘
```

**Grid**：`grid-template-columns: minmax(0,1fr) 340px; gap 24px`；右列 `position: sticky; top: 80px; align-self: start`（左滚右停）；`<1100px` 时单列堆叠，右栏整体移到左列之后且取消 sticky，作者卡内按钮横向排布。

**新增组件**：

| 组件 | 职责 | 依赖 |
|---|---|---|
| `RepoRail.tsx` | 右栏容器（作者卡+推荐列表），持有 sticky 样式 | `AuthorCard`、`RelatedList` |
| `AuthorCard` | 头像圆形（无 avatar 用品牌蓝首字母圆）、名称、主按钮「跳转 GitHub ↗」（外链）、幽灵按钮「浏览创作者其他仓库」（站内 `/user/:login`） | `repo.owner_login`、`github_url` |
| `RelatedList` | 复用 `RepoCard` 纵向 ×3 标题「同类推荐」，空态文案「同分类暂无更多仓库」 | 新 API `related(id)` |

**API 变更**（ApiClient 接口 + mock 同步实现）：

```ts
related(repoId: number): Promise<RepoCardData[]>
// 契约：同分类、排除自身、stars 降序、取前 3；不足则返回实际数量
```

related 加载失败：整个推荐区块静默隐藏，不占用错误提示通道。

**README 区块**（`ReadmeSection`）：

1. 在文件树**根级**找 `/^readme(\.(md|markdown|txt))?$/i`（大小写不敏感的首个命中）
2. 经现有 `repoFile(id, path)` 取内容
3. react-markdown + remark-gfm 渲染；不开 rehype-raw（原始 HTML 不执行）；链接 `target="_blank" rel="noreferrer"`；相对路径图片视为不可达→隐藏并保留 alt 文本
4. 找不到文件 / 加载失败 → 展示区内居中「暂无自述」（空态样式，不用整卡报错）

**保持不变的现状**：Tabs 文案与 URL 深链（`?tab=explain&file=…`）、解读占位卡、讨论区文案与位置（置于 README 之后）、登录门控、乐观更新回滚、加载失败降级。

## 4. 工程约定与验收

- 新增 npm 依赖仅两个：`react-markdown`、`remark-gfm`；其余零依赖
- 全部新颜色进 theme.css 作语义 token；组件层禁裸色值；类名沿用 BEM
- 测试：更新 RepoPage 既有测试为新布局断言；新增 ReadmeSection（渲染/暂无自述两态）、RelatedList（取数过滤/空态/失败隐藏）、IconAction（两态切换/busy/计数）单测；ProfilePage 增横幅含头断言；App 增加 app-root 结构断言
- 验收映射：①个人页背景盖至 tab 上沿 ②全部页脚沉底 ③仓库页呈现 skillsmp 式双列（含 README/推荐/解读入口）④页面底 `#F4E4C2` 生效且层次不倒挂 ⑤心/星图标按钮含计数与动效——五项在 `npm run dev` 截图目检 + vitest 通过
